## 실행 전 설정

TMDB Token은 `.env`에서 읽고, `.env`는 Git에 올리지 않습니다.
처음 clone했다면 `.env.example`을 복사해 `.env`를 만들고 Token을 채워 주세요.
(`.env`가 없으면 asset을 찾지 못해 빌드되지 않습니다.)

```sh
cp .env.example .env
# TMDB_ACCESS_TOKEN=<TMDB API Read Access Token>
```
